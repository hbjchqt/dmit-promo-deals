## DMIT 的促销逻辑，和常见的 VPS 商家不太一样

多数商家的「促销」就是首购立减，第二年续费打回原价。DMIT 主力优惠大多是**循环折扣**，也就是打折跟着续费周期一直走，第二年的账单还是折扣价。这一点直接决定了促销的实际价值——月付 9 折和循环 9 折完全是两码事。

另一部分是**账户金返还**（Credit Back）。玩法是：下单时正常用优惠码打折，成交后再按实付金额的一定比例，分 12 个月把余额退到你的 DMIT 账户里。这笔钱不能提现，但可以用来续费或者买新机器。所以宣传语里写的「最高 30% 优惠」，经常是「折扣 + 返还」叠加出来的数字，不是打折 3 折。

组合一下最常见的两档，实际到手大概是这个量级：

- 10% 循环折扣 + 5% 账户金返还，综合约等于 14.5% 的优惠，月付、季付、年付都能用
- 15% 循环折扣 + 10% 账户金返还，综合约等于 23.5%，通常只对年付开放

把返还算进去之前，先问自己一个问题：你确定还会在 DMIT 续费吗？如果只是一次性买台机器用几个月就走，返回到账户余额里的钱对你没有价值，那真正生效的只有折扣那一部分。

## 促销之外，先选对线路：Pro / EB / T1 差在哪

DMIT 三家机房（洛杉矶、香港、东京）的套餐都按回程线路分成三档，配置可以一样，价格和体验完全不同。

**Premium（缩写 Pro）**是旗舰档，三网回程走电信 CN2 GIA，中国大陆方向的延迟和晚高峰稳定性是这家的核心卖点。贵，而且贵得比较硬气。

**Eyeball（缩写 EB）**是中间档，主走 CMIN2 / 9929 这类中国方向优化线路。价格比 Pro 低一截，流量给的更大方，适合预算有限但希望国内访问别太难看的人。

**Tier 1（缩写 T1）**是纯国际 BGP 线路，没有针对中国大陆做优化。它的优势在价格和流量：最低配可以做到 4Gbps 端口、月流量一两个 TB，超量之后不关机，只降速到 100Mbps 继续跑。做中转、备份、CI/CD、面向海外用户的站点，这档才是性价比的正确打开方式。

如果你主要用户在国内、对延迟敏感，别为了省几十美元买 T1，电信回程走国际线路的体感差距足以让你后悔。

这里有个值得注意的变化：香港的 Eyeball 系列已经下线，现在香港机房基本只剩 Premium 和 Tier 1 两条线。买之前别照着两年前的老文章找 HKG EB 套餐，链接会指向已经不存在的产品。

## 下单前的几个确认项

**库存**。DMIT 的高配款和特价款常年缺货，第三方整理的「在售清单」和下单页经常不一致。看到合适的配置，先点进订单页确认能不能加进购物车，再决定要不要等。

**平台代次**。同样的线路会挂在 AS3（AMD EPYC 7003）、AN4（EPYC 9004）、AN5（EPYC 9005）不同平台上。AN5 单核性能更好、硬盘更大，价格也更高。多数建站和代理场景感知不到 AS3 和 AN5 的差距，预算紧的时候 AS3 更划算。

**超量后的限速值**。T1 系列超量后还能跑 50Mbps 到 500Mbps 不限量，Pro 和 EB 系列超量后普遍只有 4Mbps 到 10Mbps。这个数字写在表格最右边，但它对实际体验的影响比 CPU 核心数大得多。

**换 IP 政策**。Pro 和 EB 系列在符合条件时支持免费更换 IP，对做站的人来说是刚需，买之前值得确认当前规则。

**支付方式**。支付宝、微信支付、PayPal、信用卡都可以，这一点对国内用户比较友好，也省了代购的麻烦。

## 几个常被问到的问题

**优惠码能叠加吗？** 不能。一单一个码，多填会覆盖。

**返还的账户金能提现吗？** 不能。额度进账户余额，只能用于后续消费。

**老用户能享受促销吗？** 往期活动对新老用户都开放，但优惠码只作用于新购订单，已有机器的续费账单打不上折扣。想把老机器换成折扣价，通常的做法是新开一台、把业务迁过去。

**促销什么时候出？** 从往年节奏看，圣诞和年末是力度最大的一轮，黑五、节假日会放短期限时码。平时官网偶尔挂补货款，但没有额外折扣。

**T1 便宜是不是坑？** 不是坑，是定位不同。它不针对中国大陆优化，电信用户晚高峰可能比美西 Pro 还慢。如果你的用户全在海外，或者只是需要一个中转节点、备份机，T1 就是这家里最值钱的产品线。

总结成一句话：DMIT 的「促销」是一套按线路和付款周期分层的循环折扣体系，不是随便找个码就能打折。先定线路，再定周期，最后拿对应的码去 Validate Code 验证——顺序反了，怎么试都是白试。
